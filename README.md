Về Cơ sở dữ liệu (Database):

Phân tích yêu cầu và thiết kế Sơ đồ thực thể liên kết (ERD) cho hệ thống bán hàng.

Xây dựng và chuẩn hóa các bảng dữ liệu (Tables), thiết lập khóa chính/khóa ngoại (Primary/Foreign keys) tối ưu cho việc truy vấn.

(Nếu có dùng SQL/Entity Framework thì thêm): Viết các câu lệnh truy vấn SQL / Sử dụng Entity Framework Core để kết nối CSDL với Backend C#.

Về Kiểm thử phần mềm (Testing):

Xây dựng kịch bản kiểm thử (Test Scenarios) và viết các Test Cases chi tiết cho từng chức năng của website (Đăng nhập, Thêm vào giỏ hàng, Thanh toán...).

Thực hiện kiểm thử các trường hợp ngoại lệ (Edge cases) để phát hiện và báo cáo bug, giúp nhóm cải thiện tính bảo mật và logic của hệ thống.
